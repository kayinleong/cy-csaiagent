| job → escalations | The job writes escalations as the service account; must not be triggerable by an unauthenticated caller |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-01-33 | Spoofing | Forged/unsigned cron callback triggers escalations as the service account | mitigate | `verifySignatureAppRouter` HMAC verification; test asserts unsigned rejected; signing keys from Secret Manager |
| T-01-34 | Denial of Service | Stall cron lapses silently; proactive value dies overnight | mitigate | Heartbeat doc per run + (Phase-2) UI watchdog banner; QStash retries+DLQ (not a free cron) |
| T-01-35 | Tampering | Duplicate escalation spam for the same stalled agent | mitigate | `emitHandoffSignal` dedup guard per agent+reason+window (test asserts no duplicates) |
