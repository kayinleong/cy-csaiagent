<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| admin form → KB mutation | Only admin role may create/edit KB docs; the Server Action must re-check the role |
| browser → /api/kb/ingest/process | The poll worker is a privileged Route Handler; must require an authenticated admin |
| uploaded file → ingestion | A large/crafted file must not be processed in one request (timeout/DoS) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-30 | Elevation of Privilege | Non-admin creating/editing KB docs | mitigate | `requireUser` admin gate on the page + the Server Action + the ingest route; rules (01-03) restrict kbDocs writes to admin |
| T-01-31 | Denial of Service | Mega-PDF processed in one request (Cloud Run timeout) | mitigate | Chunked client-driven poll loop with a SPIKE-INGEST batch budget; grep asserts no `after()` inline embedding |
| T-01-32 | Tampering | Duplicate/duplicated chunks corrupting retrieval | mitigate | sha256-keyed idempotency; re-ingest of the same file does not duplicate (test asserts) |
</threat_model>
