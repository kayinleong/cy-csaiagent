| T-04-DOWNLINE | Information Disclosure | coach read scope | mitigate | `seniorCoachId == request.auth.uid` rule + denormalized seniorCoachId on write (Pitfall D); rules.test.ts asserts coach-other-downline denied. |
| T-04-TENANT | Information Disclosure | cross-tenant read | mitigate | Converter stamps tenantId; `sameTenant()` on every read; rules.test.ts cross-tenant deny case. |
| T-04-EDIT-PII | Information Disclosure | captureReplyEdit logging | mitigate | originalDraft/editedFinal stored but never logged; only counts logged (CLAUDE.md no-PII-in-logs). |
