## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → (admin) System & Compliance page gates | read-only + non-admin denied at every page gate |
| publishModelConfig args → Remote Config backend | pillar + modelId cross from the client; only the 5 known keys may be written; concurrent publishes must not blind-overwrite |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
