<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → inventory admin page | Only admins may load the page (RSC gate) and only admins may mutate (Server Action re-check + rules). |
| uploaded CSV/JSON → importProjectsAction | Untrusted file content; validated per-row by src/inventory/import.ts before any write. |
| collateral input → stored reference | Only a Storage path / external URL string is accepted; no Drive picker. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-22 | Elevation of privilege | inventory admin page + Server Actions | mitigate | RSC requireUser→role==='admin' gate (redirect non-admins); every Server Action re-checks admin via getSessionUser() AND the core assertAdmin (defense in depth); Firestore rules deny non-admin writes. (ASVS V4; T-01-30 carried) |
| T-03-23 | Tampering / Input validation | CSV import via UI | mitigate | importProjects validates each row against required ProjectDoc fields before write; per-row errors surfaced; no partial/invalid writes. (ASVS V5) |
| T-03-24 | Information disclosure | collateral via Drive | mitigate | UI offers Storage path / external URL only; grep gate proves no Drive picker. (C2/D-09) |
| T-03-25 | Spoofing | client supplies role in body | mitigate | Role read from the VERIFIED session token (requireUser), never from the form body. (carried platform invariant) |
</threat_model>
