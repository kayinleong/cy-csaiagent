<objective>
Build the Finder agent — `src/agents/finder/*` — mirroring the Coach agent pattern 1:1 (scoped prompt + read-only AI-SDK tools + Zod output schema + a grounding-miss → refusal signal). This is the second pillar (SC1, SC3).

Three load-bearing behaviors: (1) an LLM criteria-parser (`generateObject` + `CriteriaSchema`) turns pasted free text into a typed query and emits `unknown` for missing eligibility-critical fields rather than inventing them (Pattern 3, Pitfalls 23/36); (2) the tools are READ-ONLY and delegate availability/eligibility/affordability entirely to the deterministic `searchProjects` from 03-02 — the model can explain a refusal but never override the gate (anti-pattern); (3) each match carries a "why this match" rationale grounded in the project's real fields + the matched criteria, citing the projectId, and a sub-threshold/ineligible lead gets a grounded refusal — never a fabricated project (D-04/D-05).

| model → recommendation output | The model can only recommend tool-returned active records; refusal is grounded, not fabricated. |
