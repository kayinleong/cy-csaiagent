<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| agent input → comprehension grader | Free-text paraphrase crosses to the embedder/judge; must not be a privilege path. |
| Coach tools → Firestore | Tools read agentProfiles/KB as the service account; must stay read-only. |
| journey advance → agentProfiles write | A state-advancing write must be gated by a passing comprehension grade, not client-assertable. |

## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-15 | Tampering | journey checkpoint advance | mitigate | Advance is a server-side write gated by `gradeParaphrase` pass; the AI SDK tool is read-only (no write), so a model/agent cannot self-advance without the graded gate. |
| T-02-16 | Spoofing | hallucinated grounding | mitigate | Grounding mandate preserved: cite real [KB:chunk-id]; KB-miss → emitHandoffSignal; coach.test.ts asserts no-invent-on-miss. |
| T-02-17 | Info-disclosure | comprehension answer logging | mitigate | gradeParaphrase never logs raw answer text; only the numeric score is returned/persisted. |
| T-02-18 | Tampering | KB-doc-referenced journey content | accept | Journey references KB docIds; content is governed by admin publish/version (02-02/02-08); the journey config holds IDs, not content. |
</threat_model>
