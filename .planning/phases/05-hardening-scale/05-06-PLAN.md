## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser (admin) → conversation read | Admin reads any subject's thread — must be audited (HR-5) and read-only |
| browser (admin) → role assignment | Admin changes another user's privileges — must be admin-gated + go through the sole claim path |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-ADMINGATE | Elevation of Privilege | non-admin reading conversations or assigning roles | mitigate | Three-layer gate; role from verified token; action tests assert Forbidden |
| T-05-UNAUDITED | Repudiation | reading subject conversations without an audit trail | mitigate | auditDrilldown(user.uid, conversations/${cid}) BEFORE returning any messages (HR-5); enforced by test order |
| T-05-RW | Tampering | the viewer mutating conversation data | mitigate | Read-only surface — no mutating export; acceptance grep forbids a write path |
| T-05-CLAIM | Elevation of Privilege | claims set outside the sanctioned path (bypassing role-union validation) | mitigate | Only setUserClaims (auth.ts:148) writes claims; no direct setCustomUserClaims; role-assign audited |
| T-05-SELFDEMOTE | Denial of Service | admin accidentally removing all admin access | mitigate | Demotion AlertDialog confirm (HR-6) before the write |
</threat_model>
