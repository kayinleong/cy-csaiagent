|----------|-------------|
| client → Firestore | Browsers can attempt direct reads/writes; rules are the only client-side guard |

| T-05-TAMPER | Tampering | client forging usageEvents/usageRollups/erasureRequests docs | mitigate | `create,update,delete: if false` for all clients (mirror auditLogs/replyEdits); per-collection assertFails tests |
